## Ruta sugerida de lectura
**HTML → CSS → JavaScript → JSX → React**. HTML describe los elementos; CSS los presenta; JavaScript aporta comportamiento; JSX permite expresar una interfaz desde JavaScript; React la actualiza a partir de estado y propiedades.

## Cómo usar estas notas
- Busca por concepto: `label`, `onChange`, `...prev`, `display: flex`, etc.
- Los ejemplos son genéricos; no dependen de un backend, API ni framework de estilos particular.
- Los fragmentos con `tsx` requieren un entorno React/TypeScript; los ejemplos `html`, `css` y `js` pueden estudiarse por separado.
